## 正文文案

整理了 2020-2026 年广东省考职位表，做成了一个可交互的数据看板。

最明显的结论是：近年招录不是一路扩招。
2020-2023 年全省招考人数持续上行，2024-2025 年维持在 1.7 万人左右的高位平台，2026 年回落到 11,779 人。

所以选岗不能只看总量，更要继续下钻：

1. 你的专业近几年是在扩张还是回落？
2. 这个专业在哪些城市岗位更多？
3. 应届占比高不高？
4. 是否经常和其他专业一起共招？
5. 城市机会是集中在珠三角，还是非珠三角也有空间？

网页里可以直接看专业排名、趋势总览、综合对比、专业 x 地域、城市年度趋势、应届和学历结构。
