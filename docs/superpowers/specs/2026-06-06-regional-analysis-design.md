# 广东省考地域维度分析 — 设计文档

## 概述

在广东省考职位表数据看板中新增**地域维度分析**页面，基于 2020-2026 年全部职位表数据，从城市/地域视角展示广东省公务员招录的分布格局与变化趋势。

## 数据方案

### 数据提取

编写 `scripts/extract/extract_city_data.py`，从原始 10 个 `.xls` 职位表文件提取城市维度数据。

**每条记录提取字段：**
- `year` — 年份（2020-2026）
- `city` — 考区城市名
- `recruits` — 该职位招录人数
- `education` — 学历要求
- `fresh_type` — 应届类型（social / fresh_any / fresh_current）
- `unit` — 招考单位
- `position` — 职位名称

**聚合计算：**
- 各城市总招录人数、总职位数
- 各城市年度招录趋势（2020-2026）
- 各城市学历结构（研究生/本科/大专）
- 各城市应往届比例（社会/应届/当年应届）
- **新增：** 专业×城市矩阵 — 从 `all_majors_ranking.json` 的 `raw_ranking` 中提取每个专业在各城市的招录分布

## 页面设计

### 整体布局

- 与现有专业分析看板保持统一的**编辑式财政报告**视觉风格（深海军蓝 #16233a / 暖金色 #b8952e / 暖纸色背景 #fdf6e3）
- 使用 ECharts 5.5 作为图表引擎
- 单页 HTML，6个 Tab 切换不同分析维度
- 统计数据栏展示全局指标（22个城市 / 总招录人数 / 珠三角占比 / 招录增长最快城市）

### 城市分组定义

珠三角 9 市：广州、深圳、珠海、佛山、东莞、中山、惠州、江门、肇庆
非珠三角 12 市：汕头、汕尾、潮州、揭阳、梅州、河源、韶关、清远、云浮、阳江、茂名、湛江
省直（省级机关）单独归类，不属上述两组。地图上省直标注在广州市区。

### Tab 详情

#### Tab 1: 🗺️ 地图总览
- 广东省 ECharts 地图，颜色深度 = 招录密度（每万人招录数）。使用 ECharts 的 `map` 图表类型，加载广东省 GeoJSON 作为地图数据。
- 鼠标悬浮显示城市名+总招录数（tooltip）
- 点击城市弹出详情卡片（echarts 的 `events` 监听 `click`），使用自定义浮层展示：
  - 该城市 2020-2026 招录趋势迷你折线图（内嵌小 ECharts 实例）
  - 学历分布柱状图（研究生/本科/大专）
  - 应届类型比例
  - 热门招录专业 Top 5
- 珠三角 vs 非珠三角分区用不同底色区分（在地图上叠加分区边界）
- 右上角提供切换：显示模式（绝对招录数 / 每万人招录比 / 招录增长率）

#### Tab 2: 📊 城市排名
- 横向柱状图展示 22 个城市招录总量排名（降序）
- 排序切换：按招录人数 / 职位数 / 增长率 / 应届占比
- 下方详细数据表格（城市名 / 招录人数 / 职位数 / 应届占比 / 增长率 / 人均职位招录数）
- 搜索筛选城市

#### Tab 3: 📈 年度趋势
- 折线图展示 2020-2026 年各城市招录人数变化
- 默认显示 Top 6 城市（广州、深圳、省直、佛山、东莞、惠州）
- 可通过多选下拉框选择任意城市对比（最多 8 条线）
- 图表下方附年均增长率排名

#### Tab 4: 🎓 应往届 × 学历
- 分两栏布局：
  - 左：堆叠柱状图 — 各城市应届/社会/当年应届招录人数
  - 右：堆叠柱状图 — 各城市研究生/本科/大专学历分布
- 点击柱状图可查看具体比例数据

#### Tab 5: 🎯 专业×地域交叉分析
- 专业选择下拉框（从 `all_majors_ranking.json` 的 240+ 专业中选取）
- 选中专业后展示该专业在各城市的招录分布热力图
- 视图切换：按城市看专业 Top10 / 按专业看城市分布
- 下方展示该专业在地图上的分布（调用 Tab 1 的地图组件，高亮该专业招录城市）
- 城市选择模式：选城市 → 展示该城市招录热门专业 Top 15

#### Tab 6: 📋 城市对比工具
- 选择 2-4 个城市进行并排对比
- 对比维度：总招录 / 年度趋势（叠合折线图）/ 学历结构 / 应届比例 / 热门专业 Top 5
- 适合用于"广州 vs 深圳"、"珠三角 vs 非珠"等对比分析

## 技术方案

### 实现顺序

1. **提取脚本**：`scripts/extract/extract_city_data.py`
   - 读取 10 个 XLS 文件
   - 提取每行记录的城市、招录人数、学历、应届类型
   - 按城市聚合，输出 `data/city_data.json`
   - 从 `all_majors_ranking.json` 提取专业×城市矩阵

2. **生成脚本**：`scripts/generate/generate_city_html.py`
   - 读取 `city_data.json`
   - 使用 ECharts 广东省地图（需加载广东省 GeoJSON）
   - 生成 `广东省考地域维度深度分析.html`
   - 保持与现有看板一致的设计语言

3. **集成**：在 `广东省考专业招录深度分析.html` 中新增 Tab 链接跳转

### ECharts 广东地图

- 方案：使用 ECharts `registerMap` 加载广东省 GeoJSON。GeoJSON 数据来源：
  - 优先方案：从 ECharts 官方地图数据包 (`echarts/map/json/province/guangdong.json`) 中提取
  - 备选方案：使用 `https://geo.datav.aliyun.com/areas_v3/bound/440000_full.json`（DataV 提供的省界数据）
- 地图城市名映射：GeoJSON 中的城市名需与职位表中的`考区`字段一致，不一致时建立映射表（如"梅州市"→"梅州"）
- 省直（省级机关）职位映射到广州市区坐标显示
- 颜色分段：按招录人数分 5 档（低/中低/中/中高/高），使用 `visualMap` 组件

### 专业×城市矩阵数据流

Tab 5（专业×地域交叉分析）的数据来源与计算方式：
1. 主数据来自 `extract_city_data.py` 提取的 `city_major_matrix`（每个城市→各专业招录数）
2. 该矩阵的构建方式：遍历所有职位记录，对每条记录的 `prof_fields`（专业要求字段）解析出所有要求的专业，按城市+专业累加招录人数
3. 同一职位要求多个专业时，招录人数会计入每个专业的计数（与 `all_majors_ranking.json` 逻辑一致）
4. 专业列表来自 `all_majors_ranking.json` 的 `ranking` 数组，保持专业名称一致

### 代码复用

- 复用 `gviz_common.py` 中的文件配置、表头查找、应届分类函数
- 复用 `generate_major_ranking_viz.py` 中的 HTML 模板风格（CSS、Tab 切换 JS、统计栏）
- 复用 `all_majors_ranking.json` 的专业名称列表用于交叉分析
