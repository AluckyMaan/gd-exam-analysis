## 一、设计原则

1. **一页只有一个重色、一个贵色**：墨黑 `#0C1520` 承担权威感，铜金 `#A0622F` 只标记重点（峰值、结论、关键指标），其余为纸白与灰。
2. **层级 = 字号 × 留白 × 发丝线**：取消玻璃拟态、蓝色发光、多层阴影与 999px 胶囊。
3. **图表先给结论再给坐标**：去掉不必要的轴线/刻度，保留浅网格；能直接标注就不放图例。
4. **中文字优先**：正文 15px / 行高 1.75；六档字号；数字启用 tabular-nums。

## 四、风险与回滚

- 风险 1：旧 CSS 层数多（v1–v4），新规则追加在末尾可能被内联样式覆盖 → 关键属性用 `!important`，并清理模板里的内联 padding。
- 风险 2：图表主题无法覆盖显式写死的颜色 → 在 JS 侧统一替换主色十六进制值。
- 风险 3：移动端媒体查询顺序 → 新规则自带 `@media (max-width:860px)` 块。
- 回滚：改动集中在生成器模板（CSS/HTML/JS 各一处），`git checkout -- scripts/generate/generate_merged_viz.py` 并重生成即可。
