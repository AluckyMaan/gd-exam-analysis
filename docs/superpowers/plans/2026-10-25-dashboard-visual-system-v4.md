# 看板视觉系统 v4：可读性 / 阅读体验 / 设计一致性

> 日期：2026-10-25　状态：执行中
> 上游评审：2026-10-25 视觉评审（13 个 Tab 截图 + 计算样式 + 对比度实测）

## 目标

在**不改信息架构、不改数据口径、不动数据管线**的前提下，把主看板
`广东省考综合数据分析看板.html`（由 `scripts/generate/generate_merged_viz.py` 生成）
从“深色外框 + 白面板 + 六层容器”的混搭风格，收口成**浅色画布 + 单层卡片 + 明确字号层级**的编辑部式数据产品。

三条可量化目标：

1. **读得清**：正文/表格 ≥14px，图表轴 ≥12px，所有小字对比度 ≥4.5:1（图形 ≥3:1）。
2. **看得快**：首屏内容起点从 y≈375 提前到 ≤260；每屏容器层级从 6 层降到 ≤3 层。
3. **看着一致**：颜色从 67 个 hex 收到 1 套（主色/强调/语义/分类），圆角 3 档，阴影 1 档，标题体系 2 套。

## 非目标（本次明确不做）

- 不合并/重排 13 个子 Tab（保留 `m-tab0..5`、`c-tab0..6` 的 id 与 onclick，避免破坏锚点、测试与阅读习惯）。
- 不改任何统计口径、提取脚本、JSON 数据。
- 不做字体子集嵌入（Google Fonts 保持渐进增强；只补全回退栈）。
- 不引入构建步骤、npm 依赖或 CDN（ECharts 仍用本地文件）。

## 设计决策

- **浅色优先**：页面底色 `#f3f4f2`，hero 保留深蓝作为唯一深色块；导航改为浅色 sticky 条；内容区不再套白色大面板，图表/表格各自是一张白卡片。
- **单层卡片**：`.premium-panel` 内的图表去掉内层边框，避免“卡中卡”。
- **颜色语义**：红/绿只表示增长/下降；珠三角/非珠改用海军蓝/琥珀；对比图 6 色分类盘；地图连续单色阶。
- **数字排版**：全量 `formatNumber`；百分比 1 位小数；数值列右对齐 + tabular-nums；表格去掉迷你条（与排名 pill 重复编码），压缩行高。

## 风险

- **单文件生成器**：所有改动必须进 `generate_merged_viz.py` 再重生成，禁止直接改 HTML（否则下次生成即丢失）。
- **DOM/ECharts 桩能力有限**：新增 JS 只在真实交互路径执行，加载期不依赖新 DOM API；必要时 try/catch 降级。
- **既有测试**：e2e 对移动端 KPI 两列、候选面板、表格行数有断言——hero 改为 4 KPI 后仍须 2×2 布局。
